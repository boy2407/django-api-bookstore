# 📚 Django API Bookstore (Backend)

## 🚀 Giới thiệu

Backend API cho hệ thống Bookstore xây dựng bằng **Django** và **Django REST Framework**, cung cấp dữ liệu cho frontend.

---

## 🛠️ Công nghệ

* Django
* Django REST Framework
* MySQL
* drf-yasg (Swagger)
* VNPay Integration

---

## ⚙️ Cài đặt

```bash
pip install -r requirements.txt
```

---

## ▶️ Chạy project

```bash
python manage.py runserver 192.168.1.11:8000
```

---

## 📦 Chức năng

* RESTful API for Books (CRUD)
* Async Cart Handling
* JWT Authentication & Authorization
* Email-based User Registration
* VNPay Payment Integration
